# Final Submission Checklist

## Project Document

Include these sections in the 3-5 page PDF or Word document:

- Project overview
- Technology stack
- Agent workflow design
- System screenshots
- AI usage summary
- Project summary

Recommended screenshots:

- Dashboard page
- Agent search loading/result
- Word detail page
- Review page
- Quiz page
- Learning history page
- Telegram/OpenClaw command interaction
- Mobile browser view

## Demonstration Video

Recommended 3-5 minute flow:

1. Introduce the AI Vocabulary Assistant.
2. Show public web access.
3. Run `add sanction` through Telegram/OpenClaw.
4. Show the saved word in the web UI.
5. Open the word detail page and source URL.
6. Demonstrate review and quiz.
7. Show learning statistics/history.

## Source Code Package

Include:

- `backend/`
- `frontend/`
- `config/openclaw/`
- `docs/`
- `requirements.txt`
- `Dockerfile`
- `railway.toml`
- `.env.example`
- `README.md`

Do not include:

- `.env`
- API keys
- Bot tokens
- Passwords
- `.venv/`
- Local database files
- `data/`
